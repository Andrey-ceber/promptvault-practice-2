# Итоговые проверки перед сдачей

Проверки выполнены 18.11.2026. Это наблюдавшиеся результаты, не обещание 100% покрытия или промышленной надёжности.

## Исправления после первичной реализации

1. Реальный Chrome 157 отправлял `Origin: null` при политике `Referrer-Policy: no-referrer`; собственная HTML-форма получала 403. Добавлена регрессионная проверка заголовка (RED: `no-referrer != same-origin`), политика изменена на `same-origin`. Проверки Origin и CSRF не ослаблялись. Повторный браузерный POST передал `Origin: http://127.0.0.1:8782`; некорректная переменная была отклонена ожидаемым 400, а правильные формы успешно сохранялись.
2. Независимое ревью выявило потерю границ полей в diff и склейку последней строки `-old+new`. Оба случая воспроизведены тестами RED. Теперь сравнивается однозначный JSON-снимок содержательных полей с завершающим переводом строки. В тесты добавлены границы полей, отсутствие завершающего newline, его изменение и исключение метаданных. HTTP-ожидания обновлены на документированный JSON-diff с HTML-escaping.

## Настоящий браузер и скринкаст

Полный поток выполнен реальными HTML-формами в Chrome через Playwright; данные не были заранее записаны напрямую в SQLite:

- создать «Учебный план», v1;
- отклонить пустой JSON переменных `{}`;
- подставить `topic=История`, `audience=начинающих` и увидеть точный результат;
- изменить шаблон, получить v2;
- сравнить v1 и v2;
- восстановить v1 как новую v3, сохранив историю;
- найти по `УЧЁБА`;
- скачать JSON и проверить три версии;
- убедиться, что значения предпросмотра не попали в экспорт.

Результат браузерной проверки: `versions: 3`, `format: promptvault-1`, `jsErrors: []`. Начальная неудачная автоматизация выбора select была исправлена селектором по имени; она не выдаётся за успешный прогон. В публикацию включена только завершённая запись.

`docs/demo.mp4`: настоящая запись браузера, H.264, 1440×1000, 33.320 секунды, 830414 байт, без звука. WebM оригинал перекодирован FFmpeg; это не слайд-шоу и не смонтированный макет. Кадры ввода, результата, diff и истории сохранены отдельно. Скриншот структуры репозитория добавляется при публикации.
